# AWS API Gateway 料金ガイド

## 料金体系の概要

AWS API Gateway (REST API) の料金は主に以下の要素で構成されます：

1. **API呼び出し料金**
2. **データ転送料金**
3. **キャッシュ料金**（オプション）
4. **CloudWatch Logs料金**

### ⚠️ 重要：固定費について

**AWS API Gatewayには固定費（基本料金）は一切ありません。**

- ✅ **完全従量課金制** - 使った分だけ支払い
- ✅ **最小料金なし** - リクエストが0なら料金も$0
- ✅ **前払い不要** - コミットメントや初期費用なし
- ✅ **自動スケーリング** - 容量の事前予約不要

つまり：
- API Gatewayを作成しただけでは課金されない
- リクエストが来ない限り料金は発生しない
- 開発環境で使用していない時間帯は$0

## 東京リージョン (ap-northeast-1) の料金

### 1. API呼び出し料金

| 月間API呼び出し数 | 料金 (USD) |
|-----------------|-----------|
| 最初の3億3,300万回まで | $4.25 / 100万回 |
| 3億3,300万回を超える分 | $3.00 / 100万回 |

**計算例：**
- 月間100万回の呼び出し: $4.25
- 月間1,000万回の呼び出し: $42.50
- 月間1億回の呼び出し: $425.00

| データ量 | 料金 (USD) |

- 同一リージョン内: 無料

## 現在の構成でのコスト見積もり

### 現在の設定
```yaml
Usage Plan:
  - Rate Limit: 1,000 req/sec
  - Burst Limit: 2,000

  - CloudWatch Logs: 有効
```

### コスト計算例

#### シナリオ1: 軽量利用（開発・テスト環境）
- **月間API呼び出し**: 30万回
- **平均リクエストサイズ**: 1 KB
- **平均レスポンスサイズ**: 5 KB
- **データ転送量**: 1.8 GB/月

**月額コスト見積もり:**
```
API呼び出し: 0.3M × $4.25 = $1.28
データ転送: 1.8 GB × $0.114 = $0.21
CloudWatch Logs: ~$5.00
---------------------------------
合計: 約 $6.49/月 (約 970円)
```

#### シナリオ2: 中規模利用（本番環境 - 小規模）
- **月間API呼び出し**: 500万回
- **平均リクエストサイズ**: 2 KB
- **平均レスポンスサイズ**: 10 KB
- **データ転送量**: 50 GB/月

**月額コスト見積もり:**
```
API呼び出し: 5M × $4.25 = $21.25
データ転送: 50 GB × $0.114 = $5.70
CloudWatch Logs: ~$15.00
---------------------------------
合計: 約 $41.95/月 (約 6,300円)
```

#### シナリオ3: 大規模利用（本番環境 - エンタープライズ）
- **月間API呼び出し**: 5,000万回
- **平均リクエストサイズ**: 2 KB
- **平均レスポンスサイズ**: 10 KB
- **データ転送量**: 500 GB/月

**月額コスト見積もり:**
```
API呼び出し: 50M × $4.25 = $212.50
データ転送: 500 GB × $0.114 = $57.00
CloudWatch Logs: ~$50.00
---------------------------------

```

## 追加料金要素

### CloudWatch関連
- **CloudWatch Logs**
  - データ取り込み: $0.76/GB
  - ストレージ: $0.033/GB/月
  - 保持期間: 30日（現在の設定）

- **CloudWatch Metrics**
  - カスタムメトリクス: $0.30/メトリクス/月
  - API呼び出し: $0.01/1,000リクエスト

### X-Ray トレーシング
- トレース記録: $5.00/100万トレース
- トレース取得: $0.50/100万トレース

## コスト最適化のヒント

### 1. 使用量の最適化
- **キャッシングの活用**: 頻繁にアクセスされる静的データはキャッシュ
- **リクエストの最小化**: バッチ処理やGraphQLの活用
- **圧縮の使用**: gzip圧縮でデータ転送量を削減

### 2. Usage Planの適切な設定
```yaml
開発環境:
  - Quota: 1,000 req/day
  - Rate Limit: 10 req/sec

本番環境:
  - Quota: 100,000 req/day
  - Rate Limit: 1,000 req/sec
```

### 3. ログの最適化
- 開発環境ではログレベルをERRORに設定
- 不要な詳細ログは無効化
- ログの保持期間を短縮（7日間など）

### 4. リザーブドキャパシティ（大規模利用の場合）
- 年間コミットメントで最大20%の割引

## 他のAPIゲートウェイサービスとの比較

### AWS API Gateway HTTP API（より安価な選択肢）
- REST APIの約70%の料金
- 機能は限定的（Usage Plan、API Keyなし）
- 料金: $1.00 / 100万リクエスト

### AWS ALB + Lambda
- 長時間接続が必要な場合に適している
- 固定料金 + リクエスト料金

### Amazon CloudFront + Lambda@Edge
- 静的コンテンツが多い場合に適している
- キャッシュ効率が高い

## まとめ

### 固定費 vs 従量課金

| 項目 | 固定費 | 従量課金 |
|------|--------|----------|
| API Gateway作成・維持 | $0 | - |
| API呼び出し | - | $4.25/100万回 |
| データ転送 | - | $0.114/GB |
| キャッシュ（有効時のみ） | $0.020～/時間 | - |
| CloudWatch Logs | - | $0.76/GB |

**リクエストが0の月の料金**: **$0**

### 現在の設定での料金

現在の設定（日間10,000リクエストの制限）では：
- **最大月間コスト**: 約 $12.75（300,000リクエスト/月）
- **通常利用時**: 約 $5-10/月
- **最小コスト**: $0（リクエストなしの場合）

**重要な考慮事項:**
1. **固定費なし** - 使わなければ料金は発生しない
2. OpenAI APIの料金は別途発生
3. データ転送量は応答サイズに大きく依存
4. CloudWatch Logsの料金は使用量により変動
5. 初期段階では月額1,000円以下で運用可能

### 他のサービスとの比較（固定費の観点）

| サービス | 固定費 | 従量課金 | 適用場面 |
|---------|--------|----------|---------|
| API Gateway (REST) | なし | あり | 変動トラフィック |
| API Gateway (HTTP) | なし | あり（70%安い） | シンプルなAPI |
| EC2 + nginx | あり（インスタンス料金） | なし | 高トラフィック・予測可能 |
| ECS/Fargate | 最小タスク分 | あり | コンテナベース |
| ALB + Lambda | ALB固定費あり | あり | WebSocket必要時 |
